## Challenge Name: CanYouSee (Easy)
- **Category:** Encoding
- **Concept Learned:** Trik ekstraksi metadata dan mendecode teks
- **Tools Used:** `exiftool`, `CyberChef`

### Solution Steps:

1. Unduh file quest kemudia ekstrak
2. Gunakan tool `exiftool YOUR.png`
3. Periksa teks yang di encode menggunakan base64 kemudian decode menggunakan tools anda lalu ambil flag dari output
