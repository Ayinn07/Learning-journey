## Challenge Name: Disk, disk, sleuth! (Medium)
- **Category:*Forensics*
- **Concept Learned:*How to search strings in disk images*
- **Tools Used:** `srch_strings`

### Solution Steps:

1. Unduh file disk images sesuai quest kemudian ekstrak
2. Gunakan tool srch_strings untuk memindai strings yang terdapat dalam file disk images tersebut
   `srch_strings YOUR.img | grep CTF`
